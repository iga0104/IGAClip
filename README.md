# IGAClip

**Android / Windows 10・11向けのオフライン動画編集ソフト。**

IGAClipは、インターネット接続がない環境でも快適に動画編集を行えることを目指して開発している動画編集ソフトです。

シンプルな操作性と豊富な編集機能を両立し、日常的な動画編集をより手軽に行えることを目標としています。

## Features

- **動画・画像編集**：複数の動画や画像を読み込んで編集
- **タイムライン編集**：クリップの分割・複製・削除・並べ替え
- **テキスト編集**：文字の追加、位置・サイズ・色・アニメーションの調整
- **音声編集**：音量調整、フェード、トリミング、複数音声の配置
- **映像調整**：明るさ・コントラスト・彩度・フィルター
- **トランジション**：フェードやスライドなどの場面転換
- **プロジェクト保存**：編集内容を保存・読み込み
- **動画出力**：MP4形式での書き出し

## Offline First

IGAClipは「ネットがなくても快適に」をコンセプトに開発しています。

インターネット環境に依存しない動画編集を目指しています。

※動画出力に必要なライブラリなど、環境によっては追加の準備が必要になる場合があります。
